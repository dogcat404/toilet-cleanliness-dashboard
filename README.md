# Toilet Cleanliness Analytics Dashboard

An interactive Power BI dashboard for analyzing toilet cleanliness survey responses in the Business Statistics Department.

## Project Overview

This project aims to transform survey responses into an interactive dashboard that helps users explore perceived toilet cleanliness, compare ratings across facilities, and identify areas that may require improvement.

## Objectives

- Analyze cleanliness ratings across six aspects.
- Compare assessments by respondent status and toilet location.
- Identify facilities with the lowest average ratings.
- Present survey results through interactive visualizations.

## Tools & Technologies

- **Microsoft Forms** — Survey data collection
- **Microsoft Excel** — Data storage and preparation
- **Microsoft Power BI Desktop** — Dashboard development
- **DAX** — Measures and KPI calculations
- **GitHub** — Project documentation and version control

## Dashboard Features

- Overall average cleanliness rating
- Total number of assessments
- Average ratings by facility aspect
- Priority facility identification
- Respondent status and toilet location filters

## Survey Dimensions

The dashboard evaluates six aspects:

1. Floor cleanliness
2. Toilet cleanliness
3. Sink and faucet cleanliness
4. Odor and ventilation
5. Water availability
6. Soap availability

## Methodology

1. Collect survey responses.
2. Prepare and validate the data.
3. Develop measures and calculations in Power BI.
4. Build interactive visuals and filters.
5. Identify aspects with lower average ratings for further review.

## Data & Limitations

Survey ratings represent respondents' perceptions and may not represent an objective inspection of sanitation conditions.

If synthetic data is used for dashboard testing, it must be clearly labeled as synthetic and must not be presented as actual survey findings.

## How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Power BI Desktop.
3. If prompted, configure the data source using an authorized dataset.
4. Refresh the data and explore the dashboard filters.

## Disclaimer

This project is intended for educational and portfolio purposes. Recommendations should be validated against actual survey data and, where appropriate, direct facility inspections.
